Cómo se relaciona con la cartulina y la guía

La vista «Cartulina real» conserva la fotografía original, con su sello y firma. El carrito sigue visualmente el trazo. La fotografía tiene perspectiva; para medir alturas usa «Perfil a escala».

El perfil pasa por (0, 70), (30, 30), (60, 50) y (90, 20) m, con una salida horizontal hasta x = 105 m. Las posiciones horizontales son una idealización de la cuadrícula; las alturas son 70, 30, 50 y 20 m. Entre puntos se utiliza una curva suave.

Sin fricción: Eₘ = mgh + ½mv² = constante. Con fricción: Eₘ + Q = E₀. La fuerza disipativa constante se calcula como F = Q₁→₂ / longitud₁→₂, y Q = F·s. No se utiliza un coeficiente μ. El valor inicial de 0.150 J entre 1 y 2 sigue el ejemplo de la guía.

El punto inicial tiene una pendiente suave para permitir la salida desde el reposo. Si no hay energía para superar una subida, la simulación se pausa en el punto de retorno. Al terminar el tramo se congela la animación, conservando la rapidez calculada: no se modelan frenos. Se omiten resistencia del aire y rotación de las ruedas.
